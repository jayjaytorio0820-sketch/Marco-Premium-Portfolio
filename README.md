# Marco Premium Portfolio

A modern, bright "sunrise" one-page portfolio for Marco. Works on laptop, tablet and phone.

## What's on the page
Hero · About (with résumé download) · Selected work · Experience · Skills & tools · Gallery · Services · How we'll work together · Contact form

## How to add gallery photos
1. Upload the photo into `assets/gallery/`
2. Open `gallery.js` and add a line like:
   `{ src: "assets/gallery/my-photo.jpg", caption: "Short description" },`

## Things to replace with real info
- Text in `index.html` (about, projects, experience, skills, email, social links)
- `assets/Marco-Resume.pdf` (sample résumé)
- Email address `hello@marco.example` in `index.html` and `main.js`

## Files
- `index.html` – page content
- `style.css` – colours, fonts, layout
- `main.js` – gallery, mobile menu, contact form
- `gallery.js` – list of gallery photos
